판정 기준
· window.opener 가 null 이어야 PASS — 값이 있으면 열린 페이지가 원래 탭을 조작할 수 있습니다(rel="noopener" 누락).
· document.referrer 가 빈 값이어야 PASS — 우리 주소가 보이면 외부 사이트로 유출된 것입니다(rel="noreferrer" 누락).
· 주소창에 직접 입력해 열면 opener 는 원래 null 이라 판정이 무의미합니다. 반드시 「원본 페이지 열기」로 여세요.

이 페이지는 DirectCloud AI의 URL 출처 클릭 안전성(Q-10)을 검증하기 위한 고정 테스트 페이지입니다. 식별 키워드는 Q10-OPENER-CHECK-20260909이며, 이 문서에만 존재하는 고유 값은 안전성확인코드 4812입니다.

DirectCloud AI 답변의 출처 목록에서 URL 항목을 클릭하면 원본 페이지 열기와 AI 데이터 에디터에서 보기 두 가지 메뉴가 표시됩니다. 원본 페이지 열기를 선택하면 새 탭에서 원본 페이지가 열려야 하며, 이때 열린 페이지가 원래 화면을 조작하거나 접속 경로 정보를 가져갈 수 없어야 합니다. 이를 위해 링크에는 noopener 와 noreferrer 속성이 함께 적용되어야 합니다.

noopener 가 누락되면 열린 외부 페이지가 원래 탭의 주소를 임의로 바꿀 수 있어 피싱에 악용될 수 있습니다. noreferrer 가 누락되면 사용자가 어느 서비스에서 왔는지가 외부 사이트에 전달됩니다. 두 속성은 별개이므로 한쪽만 적용된 경우도 결함으로 판정합니다.
