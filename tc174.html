TC-174 · 부분 JS 렌더 검증 픽스처

정적 이 아래 4개 문단은 초기 HTML 에 그대로 있습니다

DCQA-PARTIAL-FIXTURE — 이 페이지는 DirectCloud AI 가 「본문 일부만 JS 로 채워지는 페이지에는 브라우저 재시도를 발동하지 않는다」는 정책을 검증하기 위한 고정 테스트 페이지입니다. 이 문단은 정적 HTML 에 포함되어 있으므로 별도 렌더링 없이도 수집되어야 합니다. 이 영역에만 존재하는 고유 값은 정적확인코드 3271입니다.

DirectCloud AI 는 등록된 URL 을 크롤링하여 본문 텍스트를 추출하고 청크로 분할한 뒤 임베딩하여 벡터 인덱스에 저장합니다. 정적으로 받은 본문이 거의 없을 때에 한해 브라우저로 다시 시도하며, 본문 일부가 이미 정적으로 확보된 경우에는 재시도하지 않습니다.

따라서 이 페이지처럼 정적 본문이 충분히 존재하는 문서는 재시도 대상이 아니며, 페이지 하단에서 스크립트가 자동으로 삽입하는 영역은 수집 범위에 포함되지 않아야 합니다. 수집 범위는 정적으로 받은 본문까지입니다.

검증 담당자는 등록 전 페이지 소스 보기로 정적 본문이 존재함을 확인하고, 등록 후 가운데 패널에서 추출된 본문 범위가 이 정적 영역까지인지 확인합니다. 그 뒤 스크립트 영역에만 있는 값을 질문해 답변되지 않는지 확인합니다.

JS 아래 영역은 스크립트 실행 후에만 채워집니다
