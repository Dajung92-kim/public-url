TC-178 · 조작해야 나타나는 콘텐츠 검증 픽스처

초기 표시 이 아래 4개 문단은 페이지를 열면 바로 화면에 보입니다

DCQA-INTERACTION-FIXTURE — 이 페이지는 DirectCloud AI 가 「조작해야 나타나는 내용(더 보기·무한 스크롤·로그인)은 수집하지 않는다」는 정책을 검증하기 위한 고정 테스트 페이지입니다. 이 문단은 페이지를 연 직후 아무 조작 없이 화면에 표시되므로 수집 대상입니다. 이 영역에만 존재하는 고유 값은 초기확인코드 2846입니다.

DirectCloud AI 는 등록된 URL 을 크롤링하여 본문 텍스트를 추출하고 청크로 분할한 뒤 임베딩하여 벡터 인덱스에 저장합니다. 추출 범위는 화면에 처음 표시되는 본문 텍스트로 한정되며, 이미지·동영상은 제외됩니다.

이 초기 표시 영역은 분량이 충분하므로 정적 본문이 거의 없는 경우에 해당하지 않습니다. 따라서 브라우저로 다시 시도하는 경로는 발동하지 않아야 하며, 수집은 이 영역까지로 끝나야 합니다.

검증 담당자는 등록 후 초기 표시분에만 있는 값을 질문해 정상 답변되는지 확인하고, 이어서 조작해야만 나타나는 영역의 값을 질문해 답변되지 않는지 확인합니다.

더 보기 아래 버튼을 눌러야 나타나는 영역

MORE-SECTION — 이 문단은 초기 HTML 소스에는 포함되어 있으나 CSS 로 감춰져 있어 페이지를 연 직후에는 화면에 표시되지 않습니다. 「더 보기」 버튼을 눌러야 비로소 나타납니다. 이 영역에만 존재하는 고유 값은 숨김확인코드 7192입니다.

사양상 이 영역은 조작해야 나타나는 내용이므로 수집 범위에서 제외되어야 합니다.
